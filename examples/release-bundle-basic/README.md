# AIIR Example: Release Evidence Bundle

This directory shows the canonical handoff artifact for AI-assisted release
evidence: a self-contained `bundle/` directory you can hand to a customer
security team, auditor, or incident reviewer and they can verify **offline**.

## Files

- `receipts.jsonl`: a small, stable input ledger (3 commits, one AI-assisted)
- `bundle/`: the generated release evidence bundle (a committed snapshot)

## Regenerate the bundle from this checkout

```bash
PYTHONPATH=../.. python3 -m aiir --release-bundle bundle \
  --receipts receipts.jsonl \
  --policy balanced \
  --subject "git+https://github.com/example/widget@v2.0.0" \
  --overwrite
```

The `created_at` and `timeVerified` timestamps change on each run, so the
regenerated bytes will differ from the committed snapshot. Everything else is
deterministic: the policy decision, coverage, receipts, and content hashes.

## What's in the bundle

| File | Role |
|------|------|
| `manifest.json` | Anchor manifest: SHA-256 of every artifact |
| `manifest.sha256` | SHA-256 of the manifest itself |
| `verify-release.json` | Full release policy decision |
| `vsa.intoto.json` | in-toto Verification Summary Attestation |
| `policy.json` | The policy that was applied |
| `receipts/` | The receipts the decision was made over |
| `evidence-stream.json` | Normalized evidence stream |
| `evidence-summary.json` | Governance-ready evidence summary |
| `auditor-report.html` | Human-readable report (a rendered *view*) |
| `verifier-instructions.md` | Exact commands to re-verify the bundle |
| `README.md` | Bundle-local overview |

## Verify the committed snapshot offline

From inside `bundle/`:

```bash
# 1. Manifest is intact
sha256sum -c manifest.sha256

# 2. Every receipt's content hash verifies (no trust in AIIR needed)
for f in receipts/*.json; do
  PYTHONPATH=../../.. python3 -m aiir --verify "$f" --explain || true
done

# 3. Re-run the policy decision over the bundled receipts
PYTHONPATH=../../.. python3 -m aiir --verify-release \
  --receipts receipts/ \
  --policy policy.json
```

The auditor report is a convenience view. The JSON artifacts are the source of
truth. The `verifier-instructions.md` inside the bundle shows the full re-check.

## Boundary

- AIIR records declared AI involvement. It does not prove hidden AI use.
- A commit without a receipt is not proof that no AI assistance was used.
- A release bundle is not a build-provenance, SBOM, or SLSA replacement; it adds
  the AI-involvement layer to that supply-chain evidence stack.
