# AIIR In VS Code

Use the extension in the same order teams usually adopt it:

- inspect an existing receipt
- initialize a repository if AIIR is not set up yet
- generate a receipt for the latest commit
- enable managed auto-receipting when you want a lower-friction local workflow
- type `@aiir` in Copilot Chat to ask about receipts, verification, and policy

The extension defaults to local-only mode and workspace-scoped settings so rollout starts from a conservative posture.
