# Support

## Getting help

| Channel | Use it for |
|---------|-----------|
| [GitHub Issues](https://github.com/invariant-systems-ai/aiir/issues/new/choose) | Bug reports, feature requests, documentation gaps |
| [GitHub Discussions](https://github.com/invariant-systems-ai/aiir/discussions) | Questions, integration help, design discussions |
| [Email](mailto:noah@invariantsystems.io) | Direct questions, partnership inquiries |
| [SECURITY.md](SECURITY.md) | Security vulnerability reports (do NOT open a public issue) |

## Response expectations

AIIR is maintained by a single maintainer. Response times are best-effort:

| Type | Target |
|------|--------|
| Security vulnerabilities | 24-hour acknowledgment, 7-day fix for Critical/High |
| Bug reports | Reviewed within 1–2 weeks |
| Feature requests | Reviewed within 1 month; no guarantee of implementation |
| Questions | Community or maintainer response as available |

For the full security response SLA, see [SECURITY.md](SECURITY.md).
